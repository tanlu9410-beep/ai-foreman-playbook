# 跨窗口交接

下一窗是陌生人。聊天记忆不是记录。交接要让一个刚醒来、没有上一窗上下文的工头，只靠系统注入和落盘文件接着干活。

本页四块是一件事：开窗交接块、抽屉、当前主线页与指纹闸、收工两拍。系统地图和手册怎么保鲜见 [`docs-upkeep.md`](docs-upkeep.md)。

窗口称 **工头席 A / 工头席 B**。不要在交接文字里写私人窗口名、聊天原文或密钥。状态标签见 [`FOR-AI.md`](../../FOR-AI.md)。本页主体 **Does**。「每次 stale 都拒」**Recommended**。

**指纹闸（与 FOR-AI 同一份）：** 载体是主线页带进度页哈希（例如内容哈希前 12 位）。工头派单时，主线页记录的指纹与进度页当前哈希不一致 → **每窗至少拦一次**；同窗第二次 stale **fail-open**（以免卡死），**不告警**。

## 解决什么问题

没有交接时，新窗口会：派已经在跑的单、忘掉未验收的完工、把进度只写在即将消失的对话里、对着过期的「当前在做什么」继续拆活。人不会去翻日志补课；工头必须在第一拍就能看见该看的指针。

抽屉若当成日记或进度真源，耐久事实会随窗口死掉，或在每一拍被整份贴进上下文。进度页改了、主线页没跟上，下一窗会按旧主线派单。

## 交给谁

| 谁 | 管什么 | 不管什么 |
|---|---|---|
| **人** | 要不要换窗、要不要上线 | 读交接块、记得上一窗做到哪 |
| **坐席的工头 AI** | 写抽屉（给本窗下一个自己）；改当前主线页；收工时把结论写进文件 | 把票板、地图、主线塞进抽屉 |
| **工人 AI** | 不参与开窗交接 | — |
| **机器** | 第一拍注入一次交接块；存抽屉；主线指纹与进度页不一致时拒派单；收工两拍催账 | 产品判断；把交接块显示成一条可见气泡 |

交接注入、抽屉、标签剥离都依赖**能改模型输入的聊天壳**。只转发用户最后一句的壳做不成这三件。见 [`FOR-AI.md`](../../FOR-AI.md) 前提。

## 最小版怎么做

### 开窗交接块

新窗口第一拍用户回合，系统把一块短文藏进模型输入，**不是**聊天气泡。同一窗口最多注入一次。构造失败：本拍中止，不要标成已经交接成功。

块里只放指针和此刻还活着的清单，不放私人聊天：

- **名称映射**：本窗是哪一席，另一席叫什么。避免把别人的活当成自己的。
- **未验收单**：已结束、工头还没 ack 的施工单。
- **投递箱**：席与席之间待人放行或待本席处理的消息。
- **告警**：未解决的主机/队列告警摘要。
- **上一窗抽屉**：若开启注入且有正文，整份附上，并标明「那是上一窗的理解，不是对本窗的规定」。

心跳、巡检、主动联系不要触发这块。

### 抽屉

给「本窗下一个自己」的整张便签，不是日记、不是票板副本。

- 整张替换，不追加。
- 只在收工或换窗时写。
- 有长度上限；超了截断或拒绝，不要句中切断后还当成功。
- 对人类隐藏；不要把全文贴进之后每一拍。
- **耐久的东西不放抽屉**：票状态、主线、地图、关票证据写文件。抽屉只放「坐在这张桌子上时怎么接着想」。

### 当前主线页与指纹闸

一个短文件，只回答：现在做什么、做到哪、下一步、卡在谁。不写参数、不写历史。字段形状见 [`FOR-AI.md`](../../FOR-AI.md) §5。

进度页（「现在做到哪」的长日志）改了之后，主线页必须带上进度页的指纹。工头派单时，若主线页记录的指纹与进度页当前哈希不一致：**每窗至少拒绝一次**。自救：读进度页最后一节，更新主线页指纹后再派。同窗第二次 stale fail-open，避免工头被永久卡住。

**Recommended：** 每次都拒；主线页超过注入上限就拒派，逼工头写短；缺「怎么算做完」一栏也拒派。

### 收工两拍

第一拍：人说「收工」或等价收工词，系统附上三问——结论写进哪了、有没有说了没做、人需要知道或做什么。

第二拍：内部工程回合（不是人的新消息），处理第一拍里答「没写 / 没做」的项，并整张重写抽屉。不要把欠账留到下一窗。

## 我们现在的版本（2026-09）

- **Does。注入一次、失败不标成功。** 开窗第一拍用户回合才注入；闸是窗口行上的已交接标记。列不可读时退回「还没有会话 id」的旧判据，避免每一拍重注。构造失败抛错，调用方中止本拍。交接正文只走模型注入路径，不是可见气泡。
- **Does。名称映射按席位。** 脚手架里写清本窗是哪一席、另一席是谁；工头席与私人聊天窗用不同句子。公开文档只保留「工头席 A / 工头席 B」这套称呼。
- **Does。未验收 / 投递箱 / 告警。** 工头席开窗块拼上本窗待审施工单、投递箱、未解决告警。工头席默认只看本窗待审，不把全局列表贴进每一拍。
- **Does。抽屉整张替换、有上限。** 坐席在回复末尾写标签块；系统保存为本窗一行，整张替换。对人类隐藏。协议教的是关窗/换窗时写，不是每拍写。
- **Does。主线页 + 指纹闸。** 工头席创建施工单前读主线页；指纹必须等于进度页内容哈希前 12 位，否则视为过期。同一窗口第一次过期拒绝，之后同窗 fail-open 以免卡死（**不告警**）。写主线页时工具会代填当前指纹。
- **Does。收工两拍。** 触发词附三问；第二拍内部回合催未完项并要求重写抽屉。

## 必须由代码强制的规矩

1. 交接块每个窗口最多成功标记一次。构造失败不得把「已交接」写上。
2. 交接块不是可见聊天。
3. 抽屉按窗口隔离、整张替换、有上限。
4. 工头席创建施工单时，主线页指纹与进度页不一致 → 拒绝（每窗至少拦一次；同窗第二次 fail-open）。
5. 主线页缺失、不可读、或缺「怎么算做完」，工头席拒绝派新单。

**Recommended（现在不是硬闸）：** 抽屉是否只在收工/换窗写，靠协议而不是拦截每一拍的写入。耐久事实是否误放抽屉，代码不查。指纹闸也可以做成「每次都拒」。

## 常见坑与我们怎么补的

1. **用「有没有会话 id」当唯一闸。** 桥接会预绑会话 id，结果第一拍不再注入；列不可读时若当成「未交接」，又会每一拍重注。可读时以已交接标记为准。
2. **把票板和主线写进抽屉。** 下一窗只读了抽屉，文件已经变了。协议写明票板仍是工作状态真源；抽屉只定位本窗此刻。耐久更新走票板 / 进度页 / 主线页。
3. **进度页改了、主线页没改。** 下一窗按旧主线派单。创建时核指纹；第一次过期拒绝并告诉工头去更新指纹。
4. **收工第一拍答「没写」然后关窗。** 欠账蒸发。第二拍是系统派出的内部回合，要求当场补文件或派单。
